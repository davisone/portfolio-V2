# Design i18n — Portfolio V2

## Objectif

Mettre en place l'internationalisation du portfolio avec trois locales :
- `fr` (defaut, sans prefixe URL)
- `en-gb` (prefixe `/en-gb/`)
- `en-us` (prefixe `/en-us/`)

Seules les pages principales sont concernees (accueil, layout, header, footer, hero, about, services, experience, projects, contact, 404).

## Architecture

### Fichiers de traduction

```
src/i18n/
  translations/
    fr.json        # francais (langue par defaut)
    en.json        # anglais base (partage UK/US)
    en-gb.json     # overrides UK uniquement
  index.ts         # helper getTranslations(locale)
  useTranslations.ts  # hook React
```

Resolution :
- `fr` -> fr.json
- `en-us` -> en.json
- `en-gb` -> en.json + en-gb.json (merge, overrides ecrasent la base)

### Configuration Astro

```ts
i18n: {
  defaultLocale: 'fr',
  locales: ['fr', 'en-gb', 'en-us'],
  routing: { prefixDefaultLocale: false }
}
```

### Routage

Pages EN = wrappers legers qui importent les memes composants et passent `locale` en prop.

```
src/pages/
  index.astro           # FR
  en-gb/index.astro     # EN-GB
  en-us/index.astro     # EN-US
```

### Hook React

`useTranslations(locale)` retourne un objet `t` avec acces par cle (t.hero.title, etc.).
Le locale est passe aux composants React via props depuis la page Astro.

### Composant LanguageSwitcher

Ajoute dans le Header pour naviguer entre les 3 locales.

### Perimetre

Pages concernees : Layout, Header, Hero, About, Services, Experience, Projects, Contact, Footer, 404.
Pages exclues (restent FR uniquement) : services locaux, glossaire, comparatifs, blog, FAQ.
